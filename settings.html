!始める前に

このコードを以下の手順で使います：
  • Googleスプレッドシートを新規作成
  • メニュー「拡張機能」→「Apps Script」を開く
  • 下のコードをすべてコピーして貼り付け
  • コード冒頭のLINE_TOKEN・SHEET_ID・ADMIN_USER_IDを編集
  • 右上「デプロイ」→「新しいデプロイ」→「ウェブアプリ」→ 実行ユーザー: 自分 / アクセス: 全員
⚠ 注意: LINE_TOKENは絶対にGitHubなど公開リポジトリにアップロードしないでください。

1LINE公式アカウントを作成

  • LINE Official Account Manager にアクセス
  • 「アカウントを作成」→ メール or LINEアカウントで登録
  • アカウント種別：一般アカウント（無料） で開始
  • 無料プランは月200通まで送信可能

2Messaging APIを有効化

  • 「設定」→「Messaging API」→「Messaging APIを利用する」をクリック
  • プロバイダーを選択（なければ作成）
  • アカウントを連携 → チャネルアクセストークン（長期） を発行・コピー
  • チャネルシークレット もコピーして控える
⚠ 注意: チャネルアクセストークンは「再発行」すると古いトークンが即座に無効化されます。GASコードに設定済みの場合は要更新。

3LINE側にWebhook URLを登録

  • LINE Official Account Manager にログイン
  • 「設定」→「Messaging API」→「Webhook URL」
  • 下の入力欄からコピーして貼り付け、保存後「検証」ボタンで確認
  • 「Webhookの利用」を ON にする

4応答設定を変更

「応答設定」で以下のように設定：
応答モードBot
あいさつメッセージOFF（任意でON）
応答メッセージOFF ← 必須
WebhookON ← 必須
💡 ヒント: 応答メッセージをOFFにしないと、自動応答が優先されてしまいGASに届きません。

5ADMIN_USER_ID と STAFF_UIDS を取得・設定

  • あなた（管理者）のLINEアカウントから公式アカウントに「テスト」と送信
  • GASスプレッドシートの「ログ」シートに記録されたuserIdをコピー
  • GASコードのADMIN_USER_IDに貼り付け、再デプロイ
  • スタッフも同様に各人のUIDを取得してSTAFF_UIDS配列に追加

1LIFFアプリを2つ作成

2HTMLにLIFF IDを埋め込む

取得したLIFF IDを各HTMLファイルに設定する必要があります：

  • order.html の liff.init({liffId: '...'}) 部分
  • mypage.html の同じ箇所
下のボタンで自動で埋め込まれた設定情報を保存できます。HTMLファイルへの直接編集は別途必要です。

3HTMLファイルを公開する

LIFFのエンドポイントにはHTTPS必須。以下のいずれかで公開：

GitHub Pages無料・簡単・カスタムドメイン可
Vercel / Netlify無料・自動HTTPS・CI連携
レンタルサーバー独自ドメインで運用したい場合

2LINE Official Account Managerで登録

  • LINE Official Account Manager
  • 「ホーム」→「リッチメニュー」→「作成」
  • テンプレートを選択（推奨：6マス）
  • 画像をアップロード
  • 各エリアにアクションを設定

3各ボタンのアクション設定

📝 注文するリンク → LIFF #1（注文フォーム）
👤 マイページリンク → LIFF #2（マイページ）
💰 支払確認テキスト送信「支払確認」
📦 注文履歴テキスト送信「注文確認」
🌐 サイトリンク → 自社サイトURL
❓ ヘルプテキスト送信「ヘルプ」
GASコードで「支払確認」「注文確認」「ヘルプ」のテキストはすべて自動応答処理されます。
